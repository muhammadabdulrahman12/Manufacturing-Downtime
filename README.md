# Manufacturing Downtime Analysis

## Project Name
**Manufacturing Downtime Analysis**

## Project Idea
Analyzing manufacturing plant data (machines, products, production log, quality checks, and downtime events) to understand the causes of downtime and its impact on production and quality.

The project covers:
- Cleaning and preprocessing the data.
- Defining the analysis questions that matter to decision makers.
- Building a Power BI dashboard that answers those questions.
- Predicting downtime for the next day of operation, and based on it, determining the number of batches to be produced.

## KPIs
- **Total Downtime** (minutes / hours)
- **Downtime %** = downtime minutes ÷ planned minutes
- **Downtime by Reason Code**
- **Availability**
- **Performance** = (ideal cycle time × total units) ÷ run time
- **Quality / Reject Rate** = units rejected ÷ units inspected
- **OEE** = Availability × Performance × Quality
- **MTTR / MTBF** (mean time to repair / mean time between failures)
- **Cost of Rejected Units** (based on unit cost)
- **Predicted Downtime & Planned Batches** for the next day
